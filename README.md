## Cursor Landing Page Clone

This project is a static clone of the Cursor homepage built as part of an assignment.

### Tech stack

- **HTML5**: Single-page semantic layout (`index.html`) with sections mirroring the Cursor marketing site.
- **CSS3**: Custom styling in `global.css` using:
  - **CSS variables** in `:root` for colors and theme
  - **Flexbox** and **CSS Grid** for layout
  - A **fixed navigation bar** and **responsive-ish** section layouts
- **No JavaScript**: The page is fully static and works without any client-side scripting.

### Project structure

- `index.html` – Main landing page markup.
- `global.css` – Global styles, layout, and theme.
- `images/` – Local PNG screenshots used in the hero and content sections.

### Features

- **Hero section** with CTA button styled like the Cursor download button.
- **Trusted by logos** section using external logo URLs.
- **Feature sections** for agents, autocomplete, and multi-surface support.
- **Testimonials grid** using cards and remote avatar images.
- **“Stay on the frontier”** section with three feature cards and screenshots.
- **Changelog** section styled similarly to Cursor’s changelog.
- **Recent highlights** content section.
- **Footer** with multiple link columns (Product, Company, Resources, Legal) and a bottom legal bar.
